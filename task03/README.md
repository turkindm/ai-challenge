# Задача 03 — Четыре стратегии решения

Программа решает одну задачу четырьмя разными способами и выводит результаты в консоль для сравнения.

## Стратегии

| # | Название | Описание |
|---|---|---|
| 1 | Обычный | Стандартный запрос без дополнительных инструкций |
| 2 | Пошаговый | Модель разбивает решение на последовательные шаги |
| 3 | Мета-промпт | LLM сначала генерирует оптимальный промпт, затем решает задачу им |
| 4 | Группа экспертов | Задача решается тремя ролями независимо: Аналитик, Инженер, Критик |

## Использование

```bash
# Задача по умолчанию (зашита в defaultTask)
./task03

# Своя задача
./task03 -message "Как организовать кэширование в REST API?"
```

## Настройка

Все промпты и задача по умолчанию задаются константами в `main.go`:

```go
const defaultTask = `...`          // задача по умолчанию
const promptSimple = `...`         // вариант 1
const promptStepByStep = `...`     // вариант 2
const promptMetaPrefix = `...`     // вариант 3 — генерация промпта
const promptExpertTemplate = `...` // вариант 4 — шаблон роли (%s = название роли)
```

Список экспертов для варианта 4:

```go
var experts = []struct{ icon, name string }{
    {"🔍", "Аналитик"},
    {"⚙️", "Инженер"},
    {"🧐", "Критик"},
}
```

## Переменные окружения

| Переменная | Описание |
