# Задача 04 — Сравнение температур

Программа отправляет один и тот же запрос к модели три раза с разными значениями параметра `temperature` и выводит результаты для сравнения.

![demo](demo.gif)

## Температуры

| temperature | Режим | Поведение модели |
|---|---|---|
| `0.0` | Детерминированный | Предсказуемые, структурированные ответы. При повторном запуске результат почти идентичен |
| `0.7` | Сбалансированный | Компромисс между точностью и разнообразием |
| `1.0` | Максимально случайный | Нестандартные идеи, неожиданные углы зрения |

## Использование

```bash
# Запрос по умолчанию (зашит в defaultTask)
./task04

# Свой запрос
./task04 -message "Как организовать кэширование в REST API?"

# Свой системный промпт
./task04 -message "..." -system "Ты опытный CTO стартапа."
```

## Настройка

Запрос по умолчанию и набор температур задаются в `main.go`:

```go
const defaultTask = `...`                    // запрос по умолчанию
var temperatures = []float64{0, 0.7, 1.0}   // значения temperature
```
