# Задача 06 — AI-агент с TUI на Bubble Tea

Интерактивный чат-агент с терминальным UI. Агент инкапсулирует логику общения с Anthropic API.

![demo](demo.gif)

## Архитектура

```
task06/
├── agent/
│   └── agent.go   # AI-агент: хранит историю, отправляет запросы в Anthropic
└── main.go        # TUI на Bubble Tea v2: ввод, рендер чата, спиннер ожидания
```

**Агент** (`agent.Agent`) — отдельная сущность с собственным состоянием:
- инкапсулирует HTTP-запросы к Anthropic API;
- принимает опции: модель, системный промпт, URL шлюза.

**TUI** построен на [Bubble Tea v2](https://github.com/charmbracelet/bubbletea) по паттерну Elm Architecture:
- `Init` → `Update` → `View`;
- асинхронный запрос к агенту через `tea.Cmd`;
- спиннер во время ожидания ответа;
- прокрутка истории стрелками ↑↓.

## Запуск

```bash
# из корня проекта
cd task06
go run .
```

## Управление

| Клавиша | Действие |
|---------|----------|
| `Enter` | Отправить сообщение |
| `Ctrl+U` | Очистить строку ввода |
| `↑` / `↓` | Прокрутить историю |
| `Esc` / `Ctrl+C` | Выйти |

## Переменные окружения

| Переменная | Описание |
|---|---|
| `ANTHROPIC_API_KEY` | API-ключ (обязательный) |
| `ANTHROPIC_GATEWAY_URL` | URL шлюза (по умолчанию: `https://api.anthropic.com`) |
